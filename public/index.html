LEITURA SEM COMPLICAÇÃO

O original fica intacto.

Abra um PDF do seu aparelho. As ferramentas criam uma camada de estudo separada, sem pedir a senha do proprietário para salvar.

  • LerUse o dedo para rolar. Navegue e ajuste o zoom na barra inferior.
  • GrifarEscolha uma cor e arraste um retângulo sobre o trecho desejado.
  • CanetaEscreva com o dedo, mouse ou caneta compatível com o navegador.
  • NotaToque na página para adicionar uma nota. No modo Ler, toque no marcador para reler.
  • BorrachaToque na marcação para removê-la. Use desfazer se precisar.

Só nesta sessão. Não há salvamento ou exportação. Fechar, recarregar ou trocar o PDF apaga as marcações. PDFs que exigem uma senha para abrir não são desbloqueados por este app.
